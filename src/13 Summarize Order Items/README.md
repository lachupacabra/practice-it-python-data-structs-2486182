# Practice It #13: Summarize Order Items

Implement helpers to read customers and order items from CSV files, then summarize item quantities by product.

`read_customers()` should return customer records with integer IDs and full names. `read_order_items()` should return order item records with numeric fields converted. `get_total_quantity_by_product()` should return a normal dictionary of product IDs to total quantity.
