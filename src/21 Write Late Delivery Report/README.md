# Practice It #21: Write Late Delivery Report

Use `DictReader` and `DictWriter` to create a small CSV report from `data/DeliveryPerformance.csv`.

Read the delivery CSV, keep only late deliveries, and write a report with these fields: `DeliveryID`, `OrderID`, `DriverID`, and `MinutesLate`.

The solved version writes `late_delivery_report.csv` inside this exercise folder.

python "src/21 Write Late Delivery Report/solve.py"
