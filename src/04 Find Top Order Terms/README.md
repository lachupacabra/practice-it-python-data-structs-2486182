# Practice It #4: Find Top Order Terms

Implement `normalize_words()` and `get_top_terms()` to identify common terms in customer order notes.

`normalize_words()` should lowercase text, replace punctuation with spaces, and split the text into words. `get_top_terms()` should count normalized words across every note, skip stop words, and return the top terms as `(word, count)` tuples.
